# Edge Card Art

Active Ashen Reach Edge Card illustrations live in this folder.

- Filenames use the stable Edge Card ID from `src/game/data/edgeCards.ts`.
- Source art is a text-free 3:4 PNG so live rules and values remain HTML text.
- Phone-visible cards use the generated sibling `*.phone.webp` derivative.
- The Host TV burn reveal uses the full PNG through the shared card-art catalog.
- New art should preserve the clean charcoal-iron, scorched-brass, cyan-signal, and restrained-amber visual language.
