# Edge Card Art

Active Ashen Reach Edge Card faces live in this folder.

- Filenames use the stable Edge Card ID from `src/game/data/edgeCards.ts`.
- Source art is a straight-on 5:7 portrait PNG split into two equal fields.
- The upper bone-enamel field contains only the printed Edge value.
- The lower charcoal field contains one original icon for the card's alternate ability.
- Card names, timing, full rules, tradeoffs, and controls remain live HTML text.
- Phone-visible cards use the generated sibling `*.phone.webp` derivative.
- The Host TV burn reveal uses the full PNG through the shared card-art catalog.
- New art should preserve the shared charcoal-iron frame, scorched-brass divider,
  pale-bone icon, warm bone value field, and restrained cyan signal gem.
