# Threat Card Art

Active Ashenreach threat card art is organized by `threatLane`.

Canonical folders:

- `red/`
- `blue/`
- `yellow/`

The lane folder is derived from `content/cards/threats/*.json` `threatLane`.
`enemyFamily` is metadata for theme, faction, filtering, and rules. It is not the primary asset folder structure.

Legacy Riftfall threat folders are not active Ashenreach threat-card paths. New missing threat PNGs should be generated into the matching lane folder:

`public/assets/cards/threats/<threatLane>/<cardId>.png`
