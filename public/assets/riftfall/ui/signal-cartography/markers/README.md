# Signal Cartography marker coins

Runtime marker coins for the public TV board.

- `players/`: six stable public player identities matching the Signal Piece IDs.
- `objectives/`: public mission meanings for route, challenge, hunt, and service objectives.

All coins are original Ashen Reach artwork, exported as 256×256 alpha PNGs. Player
colour is applied as a separate UI ring so the artwork does not encode seat order.
Objective coins may appear only for public mission targets.
