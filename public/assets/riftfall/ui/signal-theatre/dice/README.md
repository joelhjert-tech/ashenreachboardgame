# Signal Theatre Dice Material

`ashenreach-die-face.webp` is an original Ashenreach UI material generated for
the Signal Theatre battle-roll presentation.

- Runtime path: `/assets/riftfall/ui/signal-theatre/dice/ashenreach-die-face.webp`
- Purpose: texture the six CSS cube faces used by the public TV battle roll
- Values: rendered as accessible HTML text from authoritative server dice
- Rendering: React, CSS 3D transforms, and existing motion preferences
- Source imagery: original generated material; no reference-game asset or
  third-party identity is included

The high-resolution generation source and design mockups are not shipped in the
runtime asset tree.
