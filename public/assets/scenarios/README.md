# Scenario Sheet Art

Scenario sheet art for Ashenreach belongs in this folder.

Runtime paths are resolved by `src/game/data/scenarioSheetArt.ts`. New Ashenreach scenario sheet art should use `/assets/scenarios/...` paths, not legacy `/assets/riftfall/scenarios/...` paths.

If a scenario has no mapped art, the TV scenario panel falls back to a styled placeholder.

`grinning-tithe.png` is the canonical portrait sheet art for The Grinning Tithe. Its original Pallid Curator design also establishes the visual lineage for the three scenario-owned Pallid Retinue Threat cards.
