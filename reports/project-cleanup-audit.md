## Recommended Cleanup Plan

1. Commit or otherwise protect the existing host-board working changes before moving files.
2. Archive historical docs and prompt dumps listed above into `_archive/old-docs/` and `_archive/old-prompts/`.
3. Archive tracked QA/contact-sheet evidence into `_archive/old-mockups/` or `_archive/old-generated-content/`.
4. Review the uncertain zero-reference TypeScript files one by one with `npm run typecheck`, `npm run test:client`, and targeted `rg` searches before removing.
5. Generate the 10 missing threat card PNGs rather than removing their content or manifest entries.
6. After each cleanup batch, run `npm run validate:content`, `npm run typecheck`, `npm run test:client`, `npm run build`, and `npm run audit:assets`.
