# Encounter presentation specification

## Shared shell

- Category label, encounter title, tested skill/difficulty.
- Operative identity, art, relevant modifiers, exact current action.
- Board/tile remains faintly visible to preserve place.
- One public-safe result and one consequence/reward.

## Categories

- Enemy: opposed art and totals.
- Hazard: environmental frame and fixed difficulty.
- Anomaly: signal distortion plus label/shape, never colour alone.
- Tile challenge: tile art remains visible and explicitly says persistent/fixed.
- Event/choice: owner options on phone; TV says awaiting operative decision.

## Sequence

Reveal 220–360 ms → assistance/equipment window → one roll → result → consequence → cleanup → board. No duplicate outcome rows or empty acknowledgement screen.
