# Player HUD specification

## TV HUD

- Active player: name first, operative second, location, current phase, connection state.
- Inactive players collapse to name, portrait, location, Wounds/Scars, and public resources only.
- Use stable seat order, colour plus seat number/pattern, and restrained active emphasis.
- Four operatives on one sector use a stable radial/offset stack that preserves the route and tile title.

## Phone header

- Player name first; operative secondary.
- Show current tile, phase/context, Wounds/Scars, Salvage, and only the status required for the current decision.
- Do not repeat full stats above every tab.

## Acceptance

- Couch-readable at 1366×768.
- No private missions, Artifacts, Rivalry targets, or owner-only choices on TV.
- Reconnect preserves seat identity and marker order.
