# P10 Transition and Responsive Recovery — Accessibility Review

## Focus

- Operative selection focuses the first legal operative for the owning phone.
- Scenario selection focuses the selected/first legal scenario after a Host Phone mode choice.
- Mission selection, Ready, and Start focus their legal primary control when the authoritative setup ID changes.
- Non-owner phones, disabled controls, unchanged revisions, and hidden stages do not receive focus.
- React development Strict Mode no longer consumes a focus revision before the scheduled target actually receives focus.

## Waiting and announcements

- One primary required-action shell states actor, public action, and waiting/resolving state.
- The secondary player card retains identity and vitals but no longer repeats the waiting sentence.
- A waiting shell does not repeat the same `RESOLVING` value as both state and progress badge.
- `LiveStatus` remains the single assistive announcement path for the public-safe waiting detail.

## Shop controls

- All measured Shop offer/exit targets are at least 44 CSS pixels.
- Leave Shop is normal-flow, secondary, and separated from offer navigation and the global dock.
- 360×800, 390×844, and 430×932 have zero horizontal overflow.
- Long labels wrap; no control is made smaller to achieve fit.

## TV status and motion

- Primary live-status heading remains one line.
- Supporting copy may use two lines and wraps long public words instead of clipping the entire meaning.
- Required-action metadata no longer repeats actor/kind text already carried by label and detail.
- Reduced motion replaces continuous route travel with a final-step update and a 160 ms arrival state; destination and next authoritative context remain available without motion.

## Remaining bounded coverage gaps

- Active Rivalry visual play was not fabricated; automated projection/privacy tests remain the evidence for hidden information.
- Genuine server loss was not fabricated; reconnect and restoration coverage remains real, while outage presentation awaits a controlled infrastructure test.
